기록 서버 설정

모든 사용자의 미션 결과를 Google 스프레드시트 「드론 관제 미션 기록」에 모으는 설정입니다. 처음 한 번만 하면 됩니다(약 3분).

1

Apps Script 열기

아래 버튼을 누르면 새 Apps Script 프로젝트가 열립니다(script.new). 코드에 기록 시트 ID가 들어 있어 시트와 자동으로 연결됩니다. 시트를 만든 Google 계정으로 로그인한 상태여야 합니다.

Apps Script 열기 기록 시트 열기

버튼이 안 열리면: 기록 시트를 열고 메뉴 확장 프로그램 → Apps Script를 누르세요.

2

코드 붙여 넣기

코드를 복사해, Apps Script 화면의 Code.gs에 있는 내용을 모두 지우고 붙여 넣은 뒤 저장(Ctrl+S)합니다.

복사했습니다 
/**
 * 드론 관제 미션 · 전체 기록 서버
 * 연결된 스프레드시트: "드론 관제 미션 기록"
 * 사용법: 오른쪽 위 [배포 → 새 배포 → 유형: 웹 앱] / 실행 사용자: 나 / 액세스 권한: 모든 사용자 → 배포
 */
const SHEET_ID = '1llZEshS-5It_nGeqAid8HtIgwCksoG2VOfLDZRVat0w';
const HEADER = ['시각', '이름', '미션', '미션 이름', '결과', '별', '점수', '위반', '소요(초)', '착륙', '출발', '상황 조치', '실패 사유'];

function sheet_() {
  const sh = SpreadsheetApp.openById(SHEET_ID).getSheets()[0];
  if (sh.getLastRow() === 0) { sh.appendRow(HEADER); }
  return sh;
}
function safe_(v, n) {
  let s = String(v == null ? '' : v).replace(/[\u0000-\u001f]/g, '').slice(0, n || 40);
  if (/^[=+\-@]/.test(s)) s = "'" + s;
  return s;
}
function num_(v, max) { const n = Number(v); return isFinite(n) ? Math.max(-100000, Math.min(max || 100000, Math.round(n))) : 0; }

function doPost(e) {
  const lock = LockService.getScriptLock();
  lock.waitLock(10000);
  try {
    const d = JSON.parse((e && e.postData && e.postData.contents) || '{}');
    const name = safe_(d.name, 20);
    if (!name) return json_({ ok: false });
    sheet_().appendRow([
      new Date(), name, num_(d.mission, 15), safe_(d.title, 30), d.ok ? '성공' : '실패',
      num_(d.stars, 3), num_(d.score), num_(d.viol, 99), num_(d.secs, 600),
      num_(d.land, 99), num_(d.dep, 99), safe_(d.ev, 10), safe_(d.reason, 60)
    ]);
    return json_({ ok: true });
  } finally { lock.releaseLock(); }
}

function doGet() {
  const values = sheet_().getDataRange().getValues().slice(1).slice(-5000);
  const rows = values.map(r => ({
    time: r[0] instanceof Date ? r[0].toISOString() : String(r[0]),
    name: String(r[1]).replace(/^'/, ''), mission: Number(r[2]), title: String(r[3]),
    ok: r[4] === '성공', stars: Number(r[5]), score: Number(r[6]), viol: Number(r[7])
  }));
  return json_({ rows });
}
function json_(o) { return ContentService.createTextOutput(JSON.stringify(o)).setMimeType(ContentService.MimeType.JSON); }

/** 배포 전에 한 번 실행해 권한을 승인하고 연결을 확인하는 함수 */
function testConnection() { Logger.log('연결된 시트: ' + SpreadsheetApp.openById(SHEET_ID).getName() + ' / 행 수: ' + sheet_().getLastRow()); }
3

권한 승인

  1. 위쪽 함수 선택 칸에서 testConnection을 고르고 실행을 누릅니다.
  2. 권한 검토 창이 뜨면 계정을 고르고 고급 → (안전하지 않음)으로 이동 → 허용을 누릅니다. 내가 만든 스크립트라 나오는 정상 안내입니다.
  3. 아래 실행 로그에 「연결된 시트: 드론 관제 미션 기록」이 보이면 성공입니다.
4

웹 앱으로 배포

  1. 오른쪽 위 배포 → 새 배포를 누릅니다.
  2. 톱니바퀴(유형 선택)에서 웹 앱을 고릅니다.
  3. 실행 사용자: 나, 액세스 권한이 있는 사용자: 모든 사용자 → 배포.
  4. 나온 웹 앱 URL(https://script.google.com/macros/s/…/exec)을 복사합니다.
5

URL 전달

복사한 웹 앱 URL을 Claude에게 알려 주세요. 사이트에 연결해 배포하면 그때부터 모든 사용자의 결과가 시트에 쌓이고, 게임의 기록 보기에 전체 순위가 표시됩니다.
