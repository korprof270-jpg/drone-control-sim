# 드론 관제 미션

도심 드론 버티포트 관제를 3D로 단계별(미션 1~15) 훈련하는 웹 시뮬레이션입니다.

- 사이트: https://korprof270-jpg.github.io/drone-control-sim/
- 실행: 정적 파일만으로 동작합니다(빌드 없음). 3D 라이브러리 three.js r128(MIT)은 `lib/`에 포함.
- 교육용 예시이며 지명 · 호출부호 · 수치 기준은 가정입니다.

## 테스트 단계

- 첫 화면의 **테스트 단계 (10분)**: 15단계와 같은 버티포트(FATO 2 · 스탠드 6)를 10분 동안 운영합니다.
- 1분마다 난이도 Lv.1~10 상승(도착 간격 13초 → 4.4초, 공중 최대 3 → 8대, 배터리 감소, 돌발 상황 증가). 9분 무렵이 고비입니다.
- 위반 6회 이상 또는 강제 착륙 1회면 종료, 10분을 버티면 통과. 버틴 시간이 기록됩니다.

## 사용자 기록

- 첫 화면에서 관제사 이름을 등록해야 미션을 시작할 수 있습니다.
- 미션이 끝날 때마다 결과(이름, 미션, 성공/실패, 별, 점수, 위반, 소요 시간)가 기록됩니다.
- 기본값은 **이 기기(브라우저)에만** 저장됩니다.

### 모든 사용자 기록을 한곳에 모으기 (Google 스프레드시트)

설정 안내 페이지: https://korprof270-jpg.github.io/drone-control-sim/setup.html (Apps Script 열기 · 코드 복사 버튼 포함)

1. Google 스프레드시트를 새로 만들고 **확장 프로그램 → Apps Script**를 엽니다.
2. `apps-script/Code.gs` 내용을 붙여 넣고 저장합니다.
3. **배포 → 새 배포 → 유형: 웹 앱**, 실행 사용자: **나**, 액세스 권한: **모든 사용자** → 배포 → 권한 승인.
4. 나온 웹 앱 URL(`https://script.google.com/macros/s/…/exec`)을 `index.html`의 `const RECORD_URL = '';` 따옴표 안에 넣습니다.

그러면 모든 사용자의 결과가 스프레드시트 `기록` 시트에 한 줄씩 쌓이고, 사이트의 **기록 보기**에 전체 순위가 표시됩니다.
